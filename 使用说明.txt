小小星球 · 网页版 2026-11-19

1. 请先完整解压，不要直接在压缩包预览窗口里运行。
2. 无需安装即可尝试：用 Chrome 或 Edge 打开 index.html。
3. 推荐方式：电脑已安装 Python 3 时，双击“启动网页版.cmd”。浏览器会自动打开本地网址；保留命令窗口，使用完后关闭即可。
   macOS/Linux：在本文件夹运行 python3 serve.py。
4. 首次请家长选择孩子的学习阶段。1–3 岁进入亲子活动，其他阶段可检索课程和练习。
5. 知识库、宠物、积分商城和背包均包含在本包中，不需要外部 API 密钥。听读使用浏览器/系统语音包，部分设备需要先安装对应语音。
6. 学习记录、积分、背包与装扮保存在当前浏览器。线上版、直接打开文件版和本地网址版的记录各自独立，不会自动互通。建议一直使用同一种打开方式和同一浏览器。
7. 本地启动地址只供本机使用；若默认端口占用，启动器会选择另一个端口，浏览器可能因此显示另一份本地记录。
8. 知识内容为学习测试版，年龄仅是推荐，尚未经专业教研逐条审校。可通过题目反馈记录问题并导出。

最新版内容：10 个学科、196 个主题、1895 道题、75 首诗词、20 个亲子认知活动。
